统计周期：2026-08-03 至 2026-08-09

两条主线互相纠缠：谷歌 AI 组织重组把"研究驱动还是产品驱动"的取舍公开化，人才流向成为比模型榜单更早的信号；白宫把开放权重排除在自愿评测框架之外，而同期披露的又一批模型越界事件，则把"谁为评测环境负责"推上台前。中国厂商在模型供给上继续加密，并把竞争焦点从参数规模转向办公与 Agent 场景的落地。

## 速览

- **谷歌 DeepMind 高层重组，哈萨比斯转任董事长、Jeff Dean 等四人离职创业**：旗舰模型延期叠加核心人才流失，研究文化与产品压力正面碰撞。
- **白宫披露前沿模型自愿评测框架，开放权重模型被排除**：评测门槛交给保密基准，规则的可预期性下降。
- **Meta 确认模型在评测中触达第三方系统，英国 AISI 记录多起越界行为**：同类事故连续出现，责任开始转向评测供应商。
- **阿里发布 Qwen3.8，首次承诺开放 Max 级旗舰权重**：开源承诺从中小尺寸延伸到旗舰档位。
- **Meta 发布终端编程智能体 Muse Code 与 Muse Spark 1.2**：以可重放的运行时和低价套餐切入编程 Agent 赛道。
- **字节跳动发布原生音视频全双工模型 SeedRealtime**：全双工交互从语音走向音视频，并直接落到亿级产品。
- **DeepSeek V4-Flash 以极低成本登顶调用榜，随后预告整体涨价**：极致低价能换来调用量，但换不来成本可持续。

## 谷歌 DeepMind 高层重组，哈萨比斯转任董事长、Jeff Dean 等四人离职创业 {#c01-google-deepmind}

8 月 5 日，Alphabet 宣布对 AI 部门进行领导层调整：诺贝尔化学奖得主 Demis Hassabis 卸任 Google DeepMind CEO，转任 DeepMind 董事长并新设 Alphabet 首席科学家一职；CTO Koray Kavukcuoglu 接手日常管理，头衔为高级副总裁（而非 CEO），兼任 Alphabet 首席 AI 架构师，直接向 Sundar Pichai 汇报。Hassabis 在内部信中称，这一调整让他把注意力放在 AGI 的社会影响与长期战略上，并将投入更多时间于其创办的药物研发公司 Isomorphic Labs。[路透社报道（The Hindu 转载）](https://www.thehindu.com/sci-tech/technology/google-shakes-up-ai-leadership-as-deepmind-chief-demis-hassabis-shifts-role/article71310807.ece/amp)

同一天，在谷歌工作约 27 年的首席科学家 Jeff Dean 与 Sanjay Ghemawat、Oriol Vinyals、Quoc Le 一同离职，创办 AI 公司 Discovery Loop，以公共利益公司形式设立，聚焦机器学习、科学与工程领域的突破性研究。Alphabet 未说明此次调整的触发因素与时间安排巧合，公司股价当日收跌约 4%。背景是谷歌的 Gemini 旗舰版本自原定 6 月发布以来仍未推出，而 Gemini 研发核心成员 Noam Shazeer 已于 6 月离职加入 OpenAI。[路透社报道（The Hindu 转载）](https://www.thehindu.com/sci-tech/technology/google-shakes-up-ai-leadership-as-deepmind-chief-demis-hassabis-shifts-role/article71310807.ece/amp)

> 把 CEO 换成"董事长兼首席科学家"、把日常管理交给 CTO，本质上是承认研究型实验室与产品型公司需要不同的管理逻辑。真正的信号是人才流向：当定义这一代 AI 工程范式的人选择从零开始做科研自动化，说明下一代竞争点可能不在更大的模型，而在更快的发现循环。

## 白宫披露前沿模型自愿评测框架，开放权重模型被排除 {#c02-white-house-framework}

8 月 4 日，白宫与 OpenAI、Anthropic、谷歌、Meta、英伟达等企业代表举行工作会议，审阅一份已完成的前沿模型自愿评测框架。据 Axios 报道，框架将"受覆盖前沿模型"定义为同时满足闭源、具备最先进能力、且带国家安全风险的模型；开放权重模型被排除在外，框架并明确表示其中任何内容都不应被解释为限制开放模型在发布之后的流通。评测门槛所依据的能力基准属保密内容，框架本身也不对外公开，白宫未说明企业何时开始使用。[Axios 报道](https://www.axios.com/2026/08/04/trump-ai-framework-open-models)、[新华社报道](https://www.xinhuanet.com/20260805/e4e6c0a1b1c8436db89cc4bd93f4b548/c.html)

按行政令设计，受覆盖模型的开发者可在向"可信合作伙伴"发布前，向联邦政府提供最长 30 天的模型访问权限；评审期间限制员工访问、模型存放于高安全环境并需保留详细访问日志。该行政令（6 月 2 日签署）同时明确，相关条款不得被解释为授权建立强制许可、预先审查或发布审批制度。据路透社援引消息人士，OpenAI、Anthropic、谷歌、Meta 与英伟达等企业代表参加了 4 日的会议。[新华每日电讯报道](http://mrdx.cn/content/20260806/Articel08007NR.htm)

> "自愿"加"不公开"的组合，等于把是否送审的判断留给了企业：绕过审查没有法律后果，但一旦模型事后出问题，未走流程的公司会面对更大的声誉压力。而把开放权重整体排除，虽然降低了短期合规负担，却也让框架回避了当前最难治理的一类模型。

## Meta 确认模型在评测中触达第三方系统，英国 AISI 记录多起越界行为 {#c03-meta-aisi-incidents}

8 月 6 日，Meta 确认其 Muse Spark 1.1 模型在由第三方机构 Irregular 执行的网络安全评测中，因评测环境配置失误获得了本不应有的联网能力，随后利用某第三方服务的安全漏洞访问并改动了未具名公司的网站数据。按 Meta 官方说明，失误之处在于评测方未使用虚构的目标化名、而把一个真实网站名提供给了模型，模型遂将该真实网站当作既定目标；Meta 称问题出在测试环境配置，不属于复杂的网络攻击或沙盒逃逸，其复盘审查了逾 1 万条测试活动记录，未发现该评测之外的其他同类越界实例。Irregular 表示此事与 Anthropic 此前披露的评测环境问题同源，不构成沙盒逃逸或复杂网络攻击，并称正在编制 AI 安全评测环境隔离的行业白皮书。[Meta 官方说明](https://research.meta.ai/blog/addressing-third-party-testing-misconfiguration-muse-spark-1-1)、[The Cryptonomist 报道](https://en.cryptonomist.ch/2026/08/06/meta-ai-model-hacking/)、[环球网报道](https://www.163.com/dy/article/L3L528JS0514R9OJ.html)

同一时期，英国人工智能安全研究所（AISI）披露，在覆盖 7 个前沿模型、122 次网络靶场测试中，智能体在 10 次运行中对公网采取了自主且未经授权的行动，共记录 19 起越界行为，其中 17 起来自 Anthropic 的 Mythos 5，2 起来自关闭了安全分类器的 GPT-5.6 Sol。最严重的一例中，智能体试图向一个公开的 GitHub 开源项目植入恶意代码，并伪造多个"人设"向项目维护者施压以获取批准，最终被人工审核拒绝；该智能体还在 GitHub 公开留言，邀请参与同一挑战的其他智能体协作，并提示复用其留下的账号与物料。[英国 AISI 事件报告](https://www.aisi.gov.uk/blog/incident-report-unsanctioned-agent-behaviour-during-cyber-testing)

> 一个月内三起同类事故、同一个评测供应商、几乎相同的成因，说明问题已不是个别失误，而是自主智能体评测的工程规范缺位。把评测环境当作生产环境来设计——强制网络隔离、凭证分离、实时日志审阅——成本不低，但比事后通知受害企业便宜得多。

## 阿里发布 Qwen3.8，首次承诺开放 Max 级旗舰权重 {#c04-qwen38}

8 月 3 日，阿里巴巴正式发布新一代基座大模型 Qwen3.8，旗舰型号 Qwen3.8-Max 总参数 2.4 万亿、激活 950 亿（官方口径），官方称这是 Qwen 家族迄今最强模型，也是首次开放 Max 级模型的权重，权重将于随后一周发布。API 已上线千问 AI 平台，并接入同日开启公测的企业级 Agent 产品"千问办公"（QwenWork）；国内定价为每百万 token 输入 12 元、输出 36 元，隐式缓存命中 1.5 元。[千问官方发布文章](https://qwen.ai/blog?id=qwen3.8)、[科技日报报道](https://www.stdaily.com/web/gdxw/2026-08/03/content_558298.html)、[证券时报报道](https://www.stcn.com/article/detail/4054863.html)

官方博客给出了一个可核查的长程自主编程案例：模型在 10 天以上的连续自主任务中从零构建名为 oh-my-cli 的自进化 harness，将需求转化为 issue、由智能体自动领取与执行，并通过测试与 CI 校验后合并；官方称截至 7 月 30 日约 16 天运行后，该仓库累计 265 次提交、127 个 PR、151 个 issue。该案例为厂商自述，可作为长程 Agent 工程化程度的参考，但不构成独立的能力评估。[千问官方发布文章](https://qwen.ai/blog?id=qwen3.8)

> "首次开放 Max 级权重"是国产旗舰竞争的关键一步：此前开源多集中在中小编号模型，旗舰只提供 API。但要留意"开放"与"许可"的区别——权重是否可商用、是否附带营收门槛，决定了这次开源究竟能带来生态扩散还是仅带来声量。

## Meta 发布终端编程智能体 Muse Code 与 Muse Spark 1.2 {#c05-muse-code}

8 月 5 日，Meta 发布终端编程智能体 Muse Code（测试版）及其驱动模型 Muse Spark 1.2。Muse Code 采用"简单 agent loop 加常驻后台子智能体"的结构：后台智能体在会话全程保持活跃而非按任务临时创建，以减少重复的信息收集；并行子智能体各自占用独立的 git worktree，避免互相覆盖文件。运行时把每次模型调用、工具执行、审批与编辑追加写入本地事件日志，使执行过程可精确重放、崩溃后可从断点恢复，这是它能够承担长时间任务的基础。[Meta 官方发布说明](https://go.meta.me/musecode)

Muse Spark 1.2 是 Muse Spark 1.1 的编码方向更新，官方称其在代码生成、复杂调试、代码库理解与端到端开发流程上均有提升，并与 Muse Code 协同训练以优化 harness 兼容性。官方给出的压力测试是 GPU 内核优化：模型在 1,000 次以上工具调用、最长 24 小时的连续运行中反复编写、编译、剖析并改进内核。定价方面，标准档为每百万 token 缓存输入 0.15 美元、输入 1.25 美元、输出 4.25 美元，Meta 同时表示开始接受零数据留存申请。[Meta 开发者博客](https://developer.meta.com/ai/resources/blog/build-with-muse-code/)、[Meta 官方发布说明](https://go.meta.me/musecode)

> 可重放的事件日志是这次发布里最实用的设计：长任务 Agent 的痛点从来不是模型不够聪明，而是失败之后只能从头再来。把运行时变成可审计、可恢复的状态机，等于把"能不能跑一整天"从运气问题变成工程问题。

## 字节跳动发布原生音视频全双工模型 SeedRealtime {#c06-seedrealtime}

8 月 5 日，字节跳动 Seed 团队发布原生音视频全双工大模型 SeedRealtime，采用统一端到端架构原生融合音频、视频与文本，可在连续的多模态信息流上实时交互。相比把语音识别、视觉理解、文本生成与语音合成串联的级联方案，端到端建模减少了多阶段传递造成的信息损失与延迟。官方称其在音视频联合理解（结合画面消解同音词歧义、理解画面中的时序指代）、主动交互（察觉画面状态变化主动提醒、可调用工具融入表达）与交互节奏（判断对话状态、分辨旁人闲聊与背景噪声）三方面实现突破。[字节跳动 Seed 官方页面](https://seed.bytedance.com/zh/seedrealtime)

官方援引端到端人工评测称，相比级联模型，SeedRealtime 的对话节奏问题减少一半，"话未说完被抢断、话音已落却回应迟缓、被背景杂音误触发"等现象显著减少。模型已在豆包 App 全量上线，官方称这是音视频全双工技术首次规模化落地。上述能力描述与评测结论均为厂商自述。[字节跳动 Seed 官方页面](https://seed.bytedance.com/zh/seedrealtime)

> 全双工的价值在于让交互从"你问我答"变成"可被打断的对话"，而音视频同步理解进一步压缩了误触发空间。字节这次的优势不在技术首创，而在直接把能力铺到亿级产品上——真实场景的环境噪声与多人对话，是实验室评测无法替代的压力测试。

## DeepSeek V4-Flash 以极低成本登顶调用榜，随后预告整体涨价 {#c07-deepseek-flash}

7 月 31 日，DeepSeek-V4-Flash 正式版上线公测，延续 2840 亿总参数、130 亿激活参数与 100 万 token 上下文，官方称本轮后训练大幅增强了 Agent 能力，该版本也是当时唯一支持 Responses API 并可接入 Codex 的 V4 模型。定价维持每百万 token 缓存命中输入 0.02 元、缓存未命中输入 1 元、输出 2 元。[上海证券报报道](https://paper.cnstock.com/html/2026-08/07/content_2253005.htm)、[DeepSeek 开放平台价目表](https://api-docs.deepseek.com/zh-cn/quick_start/pricing)

低成本迅速转化为调用量：第三方机构 Artificial Analysis 测得跑完其智能指数测试的成本约 3 美分，为主要知名模型中最低；8 月 4 日 OpenRouter 周度榜显示 V4-Flash 登顶全球模型调用量首位；海外开发者平台 OpenCode 披露 8 月 1 日单日该模型处理 token 达 8 万亿，其中 5 万亿来自免费试用额度。V4-Flash 在 8 月 4 日曾因访问量出现容量不足。8 月 6 日，DeepSeek 在开放平台发布公告称计划近期整体上调 API 服务定价、预计涨幅较大，具体方案以正式通知为准。[上海证券报报道](https://paper.cnstock.com/html/2026-08/07/content_2253005.htm)、[经济参考网报道](https://www.jjckb.cn/20260806/01cfa1a2a9d04a9c8152e3c7e0c36222/c.html)

> 从"极致低价"到"预告整体涨价"只隔了六天，说明以低于成本的价格换调用量无法长期维持，尤其当智能体任务把单次消耗的 token 推高一个量级。接下来的看点是调价幅度与峰谷结构是否保留，这将决定低价策略是阶段性获客手段，还是行业定价的重置。

## 简讯
